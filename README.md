# Угадай мульт по песне

Локальная браузерная викторина для компании за одним экраном. Ведущий управляет музыкой и баллами, команды отвечают вслух.

## Запуск

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite, обычно `http://localhost:5173`.

Сборка для локального просмотра:

```bash
npm run build
npm run preview
```

Сервер, регистрация и база данных не нужны. Обновление страницы сбрасывает текущую партию.

## Куда класть аудио

Файлы песен лежат в `public/audio/`. В игре путь начинается с `/audio/`.

Пример: файл `public/audio/antoshka.mp3` указан в базе как `/audio/antoshka.mp3`.

Исходные ролики, с которых собрана демобаза, также лежат в папке `mp3/`. Игра читает только `public/audio/`.

Каждый ролик в демобазе длится около 10 секунд. Игровой фрагмент — первые 5 секунд (`start_time: 0`, `end_time: 5`). Границы можно сдвинуть в JSON, не меняя код.

## Как добавить песню

Откройте `src/data/songs.json` и добавьте объект:

```json
{
  "id": "song-011",
  "category": "soviet",
  "cartoon_title": "Название мультфильма",
  "song_title": "Название песни",
  "audio_file": "/audio/song-011.mp3",
  "start_time": 12,
  "end_time": 17,
  "duration": 5
}
```

Положите файл в `public/audio/`. Поле `id` должно быть уникальным. `duration` — длина фрагмента в секундах, в этой версии она равна `end_time - start_time` и составляет 5. Категория демоверсии — `soviet`. Остальные категории показаны в меню, но закрыты, пока для них нет записей и отдельной логики выбора.

Если песен в категории меньше, чем выбрано в меню, игра не начнётся и покажет сообщение.
