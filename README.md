# Угадай мульт по песне

Локальная браузерная викторина для компании за одним экраном. Ведущий управляет музыкой и баллами, команды отвечают вслух.

## Запуск

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite, обычно `http://localhost:5173`.

Сборка для локального просмотра:

```bash
npm run build
npm run preview
```

Сервер, регистрация и база данных не нужны. Обновление страницы сбрасывает текущую партию.

## Куда класть аудио

Файлы песен лежат в `public/audio/` (можно раскладывать и по подпапкам категорий, например `public/audio/disney/`). В игре путь начинается с `/audio/`.

Пример: файл `public/audio/antoshka.mp3` указан в базе как `/audio/antoshka.mp3`.

Если у песни не заданы `start_time` и `end_time`, игра автоматически выбирает случайный 10-секундный фрагмент из трека (или случайную 1 секунду в режиме Hardcore).

## Как добавить песню

1. Положите аудиофайл (`.mp3`, `.ogg`, `.wav`, `.m4a` и др., от 10 секунд) в `public/audio/`.
2. Запустите команду, чтобы автоматически добавить новые файлы в `src/data/songs.json`:

```bash
npm run sync-songs
```

Или добавьте запись в `src/data/songs.json` вручную:

```json
{
  "category": "disney",
  "cartoon_title": "Король Лев",
  "song_title": "Акуна Матата",
  "audio_file": "/audio/disney/hakuna_matata.mp3"
}
```

Поля `id`, `song_title`, `start_time`, `end_time` и `duration` необязательны:
- `id` генерируется автоматически, если не указан.
- Если не указывать `start_time` и `end_time`, для каждого раунда берётся случайный 10-секундный отрывок (1 секунда в режиме Hardcore).
- Категории в главном меню открываются автоматически, как только в них появляется хотя бы одна песня.

Если песен в категории меньше, чем выбрано в меню, игра не начнётся и покажет сообщение.
